The starter Java account project has withdrawal and deposit operations for payment, transfer, and Pix kinds, plus in-process SMS and WhatsApp scaffolding. At the baseline, event-to-recipient behavior and notification contents are incomplete. Running `./mvnw test -q` fails: `AccountEventRecipientsTest` and `NotificationPayloadTest` fail, while `AccountIsolationTest` and `AccountTransactionTest` pass.
